**完成の基準は1つ：授業で使える動画1本と復習用PDFが出ること。**器の完成度は基準ではない。

## 7. 立ち絵について（要点。詳細は `docs/research/2026-09-26-character-animation.md`）

1. **口パクのタイミングは、VOICEVOX の audio_query から決め打ちで作れる**（音声解析も GPU も要らない）。
   エンジンの時間計算（speedScale で全長を割る、93.75fps で丸める、疑問文の語尾に 0.15 秒）を再現すれば、ほぼ完全に同期する
2. **See-Through とその派生は、素材を作る道具**。音声ファイルには追従しない（PNGAL は README で明言）。
   素材は外の道具で作り、動かすのは Laterna（Remotion）側
3. **差分（目閉じ・母音別の口・表情）は FLUX.2 [klein] 4B か Qwen-Image-Edit-2511（どちらも Apache-2.0）で作り、
   変わった部分だけを元絵に貼り戻す**
4. 拡散系 talking-head を13分通しで使うのは非現実的（1〜8日と推測）。Live2D を Remotion の中で動かすのは相性が悪い
5. **商用不可の落とし穴が多い**（RMBG-2.0、FLUX.1 Kontext dev、klein 9B、Qwen-Image-2.1、THA4、InsightFace 同梱系ほか。資料 §8）

段階の提案（資料 §9）：0＝現状（話している側を明るくするだけ）→ 1＝口の開閉＋まばたき → 2＝母音5種＋表情 → 3＝揺れ → 4＝見せ場だけ動画生成。
**授業用は段階2までを推奨**（確信度70%。主因は使用場面が未定なこと）。

## 8. 運用上の注意

- ComfyUI・VOICEVOX は主人のPCで動く。画像や音声の生成を含む工程は、主人のPC上の Claude Code で回す。
- 重い手法（MAGI・full-review）は既定では使わない。Seneschal `core/loop.md` の縦の停止（同一フェーズで FAIL 2回）に当たったときだけ。
- **Remotion の無料枠は、主人が個人として使う前提**（個人は私用・商用とも無料。MP4 を受け取る側は人数に数えない）。
  学校として導入する、他の教員に展開する、といった場合は確認が要る（教育機関は書面の許可なしに非営利団体として扱われない。資料 §10）
- **VOICEVOX のクレジット**は、Kyozai の `speaker-profiles.yaml`＋`CreditSection` が自動で出している。
  キャストを変えるときは、キャラごとの規約を確かめる（資料 §10）
- **立ち絵は自作のオリジナル**。VOICEVOX 公式キャラのデザインを模写・トレースしない（Kyozai の規則を引き継ぐ）
- **止め時【提案。主人が承認すれば決定に上げる】**：Wave 1 は Fable 5.1（高エフォート）で1〜2セッションに収める。
  超えそうなら範囲を削って主人に戻す。1本目の動画が出るまで、Wave 1・2 以外の Wave を立てない
