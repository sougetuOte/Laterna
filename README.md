## 名前の由来

**Laterna（ラテルナ）はラテン語で「ランタン、灯り」。**幻灯機を指す *laterna magica*（魔法の灯り）から採った。

幻灯機は17世紀に現れ、ガラス板に描いた絵を光で壁に映し出した道具である。
19世紀には講義や学校の授業で図や写真を映す教具として広く使われた。日本では江戸期に「写し絵」として興行に使われ、
明治期には教育用の「幻燈」として学校や講演会に広まった。
**絵を映しながら、語り手が説明する** ── 掛け合いで図解を見せる解説動画の、ずっと前の祖先にあたる。

前身の Kyozai-Athanor（Athanor は錬金術の炉）が「作る場所」の名前だったのに対し、
Laterna は「映して見せる道具」の名前にした。器ではなく、授業で映す物が主役である。
